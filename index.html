Cursos JavaScript

Exemplos do repositório, com o passo a passo para rodar cada um. Alguns abrem direto no navegador; outros precisam do Node.js, porque dependem de um servidor ou de um framework.

Antes de começar

  1. Clone o repositório. Copie tudo para o seu computador com: 
    git clone [github.com](https://github.com/Roger-Kk/Cursos-JS.git)
cd Cursos-JS
    Sem Git instalado? Use o botão verde Code → Download ZIP e descompacte.
  2. Tenha o VS Code com Live Server. A maioria das pastas tem um index.html. Abra a pasta no VS Code, clique com o botão direito no index.html e escolha Open with Live Server. Se preferir, dê duplo clique no arquivo — também abre no navegador.
  3. Instale o Node.js para os exemplos que rodam no terminal ou sobem servidor. Baixe em nodejs.org. Para conferir: 
    node -v
npm -v
    Se aparecerem as versões, está pronto.
  4. Instale as dependências só nos projetos que têm package.json. Entre na pasta do curso e rode: 
    npm install
  5. Nomes com espaços vão entre aspas. Os cursos têm espaços nos nomes, então no terminal: 
    cd "Objetos - Fundamentos"
